# Runbooks

Ted-facing operational documentation. One runbook per operational task,
written as each capability lands:

- `weekly-ingest.md` — `pipeline ingest --latest` (lands with P4-1)
- `review-queue.md` — triaging the review queue (lands with P3-3)
- `pilot.md` — running/re-running the 20-episode pilot (lands with P0-6)
- `migrations.md` — applying schema changes safely

Nothing here yet beyond this index: runbooks are written against working
software, not ahead of it.

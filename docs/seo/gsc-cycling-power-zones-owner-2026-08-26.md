# GSC cycling power-zones owner decision — 26 August 2026

**Property:** `sc-domain:roadmancycling.com`  
**Source:** Google Search Console Performance, web search  
**Window:** 25 May–24 August 2026 (three months)

## Decision

- `/blog/ftp-training-zones-cycling-complete-guide` owns informational **cycling power zones**, **FTP zones**, chart, model and interpretation intent.
- `/tools/ftp-zones` owns calculator, conversion and whole-watt output intent.
- `/answers/what-percent-ftp-for-zones` remains the narrow percentage answer and routes deeper interpretation to the guide.
- `/topics/ftp-training` remains the broad FTP-definition and discovery hub.
- `/tools/ftp-test` owns test-result conversion; `/tools/masters-ftp-benchmark` owns age- and sex-qualified benchmarking.
- The guide and calculator answer different tasks, so no canonical change or redirect between them is justified.

## Release changes

- Rewrote the guide around a clear seven-zone chart, a 280 W worked example and disclosed gap-free rounding.
- Separated the seven-zone workout model from three-zone training-distribution research.
- Removed the exact-one-hour FTP claim, universal 80/20 prescription, universal Zone 3 dismissal, fabricated-style quotation and guaranteed improvement claims.
- Added six cited claim reviews, six FAQs, a five-step HowTo, reviewer scope, review date and primary-source links.
- Tightened the narrow answer so it supplies percentages without prescribing one weekly plan or competing for broad interpretation intent.
- Added the guide to `llms.txt`, `llms-full.txt`, the pinned discovery set, IndexNow submission and AI-search benchmark prompts.

Use 27 August–23 September and compare it with the matched preceding 28 days plus this three-month baseline. Record clicks, impressions, CTR, average position and page ownership for all four exact queries.

# Content Brief Template

Every new article requires an approved brief before writing begins. No exceptions. This template enforces the dominance audit gate (July 2026) and prevents cannibalisation of existing content.

---

## Gate questions (all 7 must have clear answers before proceeding)

| # | Question | Answer |
|---|----------|--------|
| 1 | What does this page rank for? | |
| 2 | What unique decision does it help the reader make? | |
| 3 | Which pillar owns it? | |
| 4 | Which page should outrank all others for the primary query? | |
| 5 | Which product does it support? | |
| 6 | What first-hand Roadman evidence does it contain? | |
| 7 | What existing page would be weakened by publishing it? | |

If question 7 identifies a page that would be weakened, the brief must explain why the new page is justified and how the existing page will be updated, merged, or redirected.

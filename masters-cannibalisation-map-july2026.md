## 5. Next Steps (Requires Search Console Data)

This map is diagnostic. Before consolidating, merging, or redirecting any pages, the following data is needed:

1. **Google Search Console → Performance → Pages** — which URLs actually receive impressions and clicks for masters queries
2. **Query-level data** — which specific queries each URL ranks for, and whether Google is splitting rankings between competing pages
3. **Cannibalisation detection** — queries where 2+ URLs appear in SERPs within a 30-day window
4. **Backlink distribution** — which pages have earned external links that would need preserving via redirects
5. **Internal link audit** — which pages the `/masters` hub and topic page currently point to, and whether they're consolidating or scattering authority

The critical groups (1 and 2) should be investigated first — "cycling over 40" and "masters cycling training plan" are likely the highest-volume queries and the ones most affected by page-level competition.
